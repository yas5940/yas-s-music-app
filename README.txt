やすの音楽練習アプリ v1

【GitHub Pagesで公開】
1. GitHubで新しい公開リポジトリ「yasu-music-app」を作成。
2. このフォルダ内の index.html、sw.js、manifest.webmanifest、icon-192.png、icon-512.png、tunerフォルダ、scoreフォルダをリポジトリのルートにアップロード。
3. Settings → Pages → Deploy from a branch → main / (root) を選び Save。
4. https://yas5940.github.io/yasu-music-app/ をSafariで開く（公開後の想定URL）。
5. ホーム画面に追加。初回はオンラインで両機能を一度開いてから、機内モードで動作確認。

【注意】
・GitHub Pagesは一般公開です。個人の楽譜データは公開リポジトリにアップロードしないでください。
・マイクはHTTPSと利用許可が必要です。学校管理iPadでは制限される場合があります。
・曲の自動保存はブラウザ内の端末ごとの保存です。重要な曲はJSONファイルで別途保存してください。
・低音チューナーは倍音で誤認識する可能性があるため実音と比較して確認してください。
